# Assets and licenses

No Habbo Hotel assets, names, or logos are used. Everything is either generated by code in this
repository (MIT) or taken from CC0 packs listed below, with the licence text committed next to the
files under `apps/web/public/models/licenses/`.

## Pixi renderer (placeholder look, `VITE_RENDERER=pixi`)

| Asset | Source | License |
|---|---|---|
| Isometric tiles, furniture placeholders | drawn procedurally in `apps/web/src/game` | MIT (this repo) |
| Avatar sprite sheets | generated at runtime by `apps/web/src/game/sprites.ts` from the `Avatar` DTO: 16×28 logical pixels, scale 2, 11 pose columns (idle, walk×4, sit, type×2, read, raise, nap) × 4 facing rows, frame key `${pose}_${facing}_${index}`, cached per avatar in `assets/generated.ts` | MIT (this repo) |
| Sounds | synthesised with WebAudio in `apps/web/src/game/sound.ts` (tool start, typing, permission, done, error, rate limit, intern, message, click); per-sound toggles and master volume persist in `localStorage` | MIT (this repo) |

The asset manifest (`apps/web/src/game/assets/manifest.ts`) maps logical names to renderer kinds: `placeholder` (iso boxes), `generated` (runtime pixel art, the default for avatars) and `sheet` (file-backed sprite sheets, reserved: `loadPainters` fails loudly until a sheet painter exists). Swapping art means changing the manifest entry, not the world code.

Downloaded, inspected and **not used** (nothing committed): KayKit Character Animations 1.2 (its 6-joint
`PrototypePete` rig differs from the Adventurers rig; the Adventurers file already embeds 76 clips),
Quaternius Universal Animation Library standard (Rigify `DEF-*` bone names, would need retargeting),
KayKit Furniture Bits 1.0 (gradient-atlas style; kept as a candidate for props). The Quaternius
Ultimate Modular Men pack was not downloaded (its page has no scriptable link and the Adventurers rig
covers the need).

Procedural (MIT, this repo): hair styles (`short | long | cap | bald | bun`) and accessories
(`glasses | headset | tie | scarf`) are meshes built in code and attached to the rig's `head`/`neck`/
`chest` bones; the server rack and whiteboard are built from boxes; floor and wall style textures are
painted on a canvas at runtime (`apps/web/src/game/three/textures.ts`).

Inspecting a model: `node scripts/inspect-gltf.mjs path/to/file.glb` prints nodes, meshes, materials,
skins and animation clip names (reads the glTF JSON chunk only, no three.js needed).
